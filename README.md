# Thunder MC — Minecraft Server Website

A rebranded and redesigned version of the previous server website, using the supplied Thunder MC logo.

## Before publishing

Open `script.js` and change:
- `serverIP` → your real Minecraft server IP/domain
- `discordURL` → your real Discord invite

The current values are placeholders:
- `play.thundermc.net`
- `https://discord.gg/yourserver`

## Files

- `index.html` — homepage
- `features.html` — server features
- `rules.html` — rules
- `staff.html` — staff team
- `news.html` — announcements
- `store.html` — store/cart
- `vote.html` — voting page
- `style.css` — electric yellow/black Thunder theme
- `script.js` — navigation, particles, IP copy, Discord and store cart
- `logo.png` — supplied Thunder MC logo

## GitHub Pages

Upload the contents of this folder to your repository and enable GitHub Pages from the repository's Pages settings. Add your custom domain later if you have one; the previous custom-domain configuration has been removed.
